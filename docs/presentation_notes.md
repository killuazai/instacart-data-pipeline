# Presentation Notes

Maximum presentation time: 5 minutes.

Focus on engineering decisions, not a line-by-line SQL walkthrough.

## 1. Pipeline

Explain the flow:

`INSTACART -> BRONZE -> SILVER -> GOLD -> DASHBOARD`

## 2. Model

Explain:

- business process
- grain
- fact table
- measures
- dimensions
- keys and relationships

## 3. Validation

Show evidence that the data is correct:

- row counts
- nulls
- duplicates
- relationships
- reconciliation

## 4. Git and Documentation

Show meaningful team contributions and explain how another engineer can take over using the repository.

## 5. Dashboard

Show how Gold data answers the business questions.
